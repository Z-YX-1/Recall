## 5. 其它质量观察（R-28b 记录）

- **"元问题"会命中规范文档本身**：问「我笔记里关于 RAG 检索质量的结论？」时，Top-1 是
  vault 里的 `project/Recall/spec/roadmap.md`（0.9348），而不是技术笔记。原因：该问题措辞
  与"规范/路线图"类文本的词汇分布更接近。**这不是 bug，是 query 类型导致的**；如果希望
  优先返回技术笔记，需要在 R-42 里讨论"是否排除 spec 类文档"或引入 query 意图分类。
- **同文档多块占位**：`Temperature 怎么影响输出的确定性？` 的 Top-3 全部来自同一篇笔记的
  不同小节——`assemble` 的同文档合并只合并 `chunk_index` 连续的块，跨小节不合并，
  因此会把同一篇文档的多个片段一起返回。若希望"多来源优先"，可在 R-42 里加多样性重排。
